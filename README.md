# AI Image Generator

This is an AI image generator where you provide a prompt and ot generates an image based on it. Using this program you can make images for any project, idea, or just to be silly and have fun. Using the cool drop-down menus you can also change the style, resolution, and the quality of you image to your own preference and liking. I hope you enjoy this AI Image Generator!!! 

If you have an adblocker (or perhaps another browser extention), it may restrict you from making a image sucessfully, unfortuantly I have since not found a way around that bug. Sorry for the inconveince, I will be working toward finding a solution.
